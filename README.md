# ☕ Coffee Shop Management System

## 📌 About My Project

I created this **Coffee Shop Management System** using Core Python.

This project is a simple console-based application that helps manage coffee shop products, orders, billing, stock, and sales.

I created this project to practice and improve my **Core Python programming concepts**.

## ✨ Features

- Admin Login
- Add Product
- View Menu
- Search Product
- Update Product
- Delete Product
- Place Order
- Stock Management
- Generate Bill
- GST Calculation
- Sales Report
- File Handling
- Exception Handling

## 🛠️ Python Concepts I Used

- Variables
- If-Else
- Loops
- Functions
- Lists
- Dictionaries
- OOP
- File Handling
- Exception Handling
- CRUD Operations

## 🚀 How to Run

1. Open the `.ipynb` file in Google Colab.
2. Run the cells one by one.
3. Select the required option from the main menu.
4. Add products and manage the menu.
5. Place an order and generate the bill.
6. Check the sales report.
